> **Purpose:** Exhaustive catalog of member needs so a duty deacon can quickly recognize and classify any incoming request. Every request gets a **primary function owner** and, where relevant, secondary collaborators. The member never self-classifies — the deacon assigns routing. Multi-function requests assign one primary owner who pulls in collaborators. When a request is unclear, use the catch-all path at the bottom.

See also: [[routing-and-functions]], [[escalation-to-elders]], [[self-help/index]], [[benevolence/index]], [[building-fund/index]]

## Part A — Taxonomy by Function

### 1. Operations

Operations covers all tangible, physical, hands-on assistance: transportation, labor, meals, and in-home support. It is the highest-volume function.

#### 1a. Transportation

| Need | Notes | Default Urgency |
|---|---|---|
| Ride to Sunday service / midweek meeting | Recurring or one-time | Standard |
| Medical appointment transport | Doctor, specialist, therapy, dialysis | High |
| Hospital discharge ride | Timing is patient-controlled — confirm day-of | High |
| Pharmacy pickup / medication delivery | Can combine with errand run | Standard |
| Airport pickup — member arriving | Coordinate with Drivers sub-lane | Standard |
| Airport drop-off — member departing | Timing-sensitive | Standard |
| Airport pickup — incoming guest/visitor | Coordinate with Welcome | Standard |
| Grocery store run for homebound | Recurring or one-time | Standard |
| Errand run (bank, DMV, store) for homebound | Standard | Standard |
| Move-in / move-out transport | Large load → may also trigger moving help | Standard |
| Ride for children (school, activities, church events) | Requires cleared driver; notify parents | Standard |
| Emergency transport (non-medical-emergency) | Stranded, car breakdown, etc. | Urgent |

> Drivers sub-lane owns execution. Operations function owns coordination and scheduling.

#### 1b. Meals

| Need | Notes | Default Urgency |
|---|---|---|
| Meal train — new baby | Coordinate with Communications for sign-up | Standard |
| Meal train — surgery recovery | Duration depends on severity | Standard |
| Meal train — serious illness / hospitalization | May be open-ended | High |
| Meal train — bereavement / loss in family | Begins at death/notification | Urgent → then Standard |
| Single meal delivery (no train) | Short-term, clear timeline | Standard |
| Holiday meal for isolated member | Thanksgiving, Christmas, etc. | Standard |
| Meals for homebound member (ongoing) | Escalate to ongoing care coordination if > 4 weeks | Standard |

> Kitchen sub-lane handles food preparation when church kitchen is used. Operations function coordinates delivery logistics.

#### 1c. Home & Yard Maintenance / Repairs

| Need | Notes | Default Urgency |
|---|---|---|
| Minor home repair (plumbing, electrical — low risk) | Safety-critical items first | Standard / High |
| Appliance repair or replacement logistics | May intersect with Finance if purchase needed | Standard |
| Yard work — mowing, weeding, general cleanup | Standard | Standard |
| Heavy yard work — tree trimming, hauling, clearing | Requires work crew coordination | Standard |
| Snow removal (driveway, walkway, steps) | Time-sensitive in storm season | Urgent |
| Storm damage assessment and cleanup | Safety first — document for insurance | Urgent |
| Accessibility modification (ramp, grab bar) | May require skilled volunteer or contractor referral | Standard |
| Moving help — packing, loading, unloading | Coordinate crew size to job scale | Standard |
| Furniture assembly or heavy item placement | Often paired with move-in | Standard |
| Pest/hazard (mold, etc.) — referral only | Deacons do NOT perform hazardous remediation | Standard |

#### 1d. Homebound & Ongoing Support

| Need | Notes | Default Urgency |
|---|---|---|
| Regular check-in visits (tangible/practical side) | Spiritual/pastoral side → Elders | Standard |
| Prescription management logistics | Pickup, delivery, refill coordination | Standard |
| Technology help at home (devices, internet) | Also see IT sub-lane under Operations | Standard |
| Accessibility or mobility aid logistics | Equipment loan referral, transport for fittings | Standard |

#### 1e. Church Operations (Events, Facility, Setup)

| Need | Notes | Default Urgency |
|---|---|---|
| Event setup and teardown | Tables, chairs, AV, signage | Standard |
| Coffee/hospitality station setup | Coffee sub-lane | Standard |
| Welcome team coordination | Welcome sub-lane | Standard |
| Security coverage for events | Security sub-lane | Standard |
| PEP (practical event production) needs | PEP sub-lane | Standard |
| IT/AV support during services or events | IT sub-lane | Standard |

### 2. Finance

Finance covers all money-related needs: benevolence (direct financial assistance), financial navigation, and capital for facilities.

> All benevolence requests must go through intake. See [[benevolence/index]] for policy, eligibility, and approval workflow.

#### 2a. Benevolence (Direct Member Assistance)

| Need | Notes | Default Urgency |
|---|---|---|
| Rent / housing payment assistance | Eviction risk → High urgency | High |
| Utility shutoff prevention (electric, gas, water) | Shutoff notice date drives urgency | High |
| Grocery / food assistance | Can overlap with Operations meal support | Standard |
| Medical bills / copays / prescriptions | Coordinate with Operations for medication logistics | Standard |
| Unexpected emergency expense (car repair, medical) | Documented need required | High |
| Childcare cost in crisis period | Time-limited; tied to documented hardship | Standard |
| Burial / funeral cost assistance | Bereavement → also notify Communications | Urgent |
| Phone / internet (when essential for employment or care) | Requires eligibility assessment | Standard |

> Intake paperwork is owned by **Administration**. Finance owns approval and disbursement. See [[benevolence/index]].

#### 2b. Financial Navigation & Referral

| Need | Notes | Default Urgency |
|---|---|---|
| Financial counseling referral | Deacons refer; they do NOT counsel | Standard |
| Budget coaching connection | Point to vetted external or internal resource | Standard |
| Debt / credit counseling referral | Nonprofit credit counseling orgs preferred | Standard |
| Benefits navigation (SNAP, Medicaid, WIC, CHIP) | Navigate enrollment; NOT legal advice | Standard |
| Tax preparation referral (VITA, etc.) | Seasonal; track referral list | Standard |

#### 2c. Crisis Fundraising for a Member

| Need | Notes | Default Urgency |
|---|---|---|
| Special collection / fundraiser for a member in crisis | Requires pastoral approval; Finance coordinates | High |
| Gift card / goods collection for a specific member | Logistics via Operations; Finance tracks | Standard |

#### 2d. Building & Facility Capital

| Need | Notes | Default Urgency |
|---|---|---|
| Major facility repair requiring funds | Submit to building committee; see [[building-fund/index]] | Standard |
| Capital improvement project support | Planning-phase; Finance + Operations collaborate | Standard |

### 3. Administration

Administration manages records, documentation, intake logistics, and information routing. They are often the first stop for a member who doesn't know who to contact.

#### 3a. Membership Records & Certificates

| Need | Notes | Default Urgency |
|---|---|---|
| Membership certificate / letter | Standard document request | Standard |
| Transfer letter to another church | Coordinate with Elders for pastoral sign-off | Standard |
| Baptism certificate copy | Pull from records | Standard |
| Confirmation / dedication certificate | Pull from records | Standard |
| Marriage certificate (church record) | Pull from records; civil copy → refer to county | Standard |
| Funeral / memorial service documentation | Bereavement → also notify Communications and Elders | Urgent |

#### 3b. Benevolence Intake & Paperwork

| Need | Notes | Default Urgency |
|---|---|---|
| Benevolence application intake | First stop before Finance review | High |
| Supporting document collection (bills, ID, statements) | Guide member; do NOT store originals insecurely | High |
| Follow-up documentation for ongoing benevolence case | Standard | Standard |

#### 3c. Visitation & Care Coordination Logistics

| Need | Notes | Default Urgency |
|---|---|---|
| Scheduling deacon visitation (practical side) | Pastoral visitation → Elders | Standard |
| Tracking ongoing care cases | Flag if exceeding capacity or going > 4 weeks | Standard |
| Coordinating multi-function request assignments | Assign primary + secondary owners | Standard |

#### 3d. Forms, Documents & Information Access

| Need | Notes | Default Urgency |
|---|---|---|
| Connecting member to a church form or document | Online or paper | Standard |
| Explaining a process or policy to a member | Point to [[self-help/index]] first | Standard |
| Directing member to correct deacon or ministry | Triage and handoff | Standard |

### 4. Communication

Communication connects members to people, ministries, and resources. It also handles outreach, guest follow-up, and language/access needs.

#### 4a. Connection to Ministries & Leaders

| Need | Notes | Default Urgency |
|---|---|---|
| Connect member to a specific ministry | Men's, women's, youth, small group, etc. | Standard |
| Connect member to an Elder (spiritual need identified) | Use [[escalation-to-elders]] protocol | High |
| Connect member to a deacon (tangible need — triage) | Route to correct function owner | Standard |
| Connect member to external community resource | Food bank, shelter, counseling org, etc. | Standard |
| Connect homebound member to church community | Phone/video check-in logistics | Standard |

#### 4b. Language & Accessibility

| Need | Notes | Default Urgency |
|---|---|---|
| Translation / interpretation (spoken) | Match language volunteer to member | Standard |
| Document translation help | Church docs or community forms — informal only; legal docs → refer | Standard |
| Sign language / ASL interpretation | MSL sub-lane; plan in advance for services | Standard |
| Large-print or accessibility format for materials | Coordinate with IT sub-lane | Standard |
| ESL support connection | Connect to ESL ministry or external program | Standard |

#### 4c. Personal Technology Help

| Need | Notes | Default Urgency |
|---|---|---|
| Help setting up email or church app | Basic setup; complex issues → IT sub-lane | Standard |
| Help with video call (Zoom, FaceTime) to stay connected | Especially for elderly / isolated members | Standard |
| Help understanding a digital form or document | Standard | Standard |

#### 4d. Guest & New Member Follow-Up

| Need | Notes | Default Urgency |
|---|---|---|
| First-time guest follow-up contact | Welcome sub-lane owns first contact | Standard |
| New member needs connection or orientation | Assign a point-of-contact deacon | Standard |
| Returning member reintegration after absence | Gentle, non-intrusive contact first | Standard |

#### 4e. Announcements & Care Coordination Communications

| Need | Notes | Default Urgency |
|---|---|---|
| Meal train sign-up coordination (broadcast) | Coordinates with Operations/Kitchen | Standard |
| Care need announcement to congregation (privacy-aware) | Member must consent to any public sharing | Standard |
| Prayer request distribution (tangible framing only) | Spiritual prayer coordination → Elders | Standard |

### 5. Redirect to Elders

The following are **not deacon functions**. When a request is primarily or substantially one of these, route to Elders via [[escalation-to-elders]].

> Key principle: **Tangible and spiritual needs often come together.** Do not abandon the tangible side when escalating the spiritual side. Coordinate so both streams move in parallel.

| Need | Elder Function | Tangible Split (Deacons Retain) |
|---|---|---|
| Marriage counseling / conflict | Pastoral care | Meals or practical support during crisis → Operations |
| Grief counseling (emotional/spiritual processing) | Pastoral care | Meal train, transportation → Operations |
| Mental health crisis (non-emergency) | Pastoral referral | Practical logistics, safety coordination → Operations |
| Mental health emergency | Call 911 first; then notify Elders | Physical presence / transportation if safe |
| Prayer for healing or a specific situation | Elder/prayer team | Meals, transport for appointments → Operations |
| Doctrinal questions or faith doubts | Elder | None |
| Confession, church discipline, reconciliation | Elder | None |
| Conflict between members | Elder | None |
| End-of-life spiritual preparation | Elder + pastoral team | Hospice logistics, transport, meals → Operations |
| Parenting / marriage guidance (spiritual framing) | Elder | Practical childcare logistics, meals → Operations |
| Addiction (spiritual/accountability side) | Elder | Transportation to meetings, meals → Operations |
| Bereavement (spiritual grief processing) | Elder | Meals, transport, paperwork logistics → Operations / Admin |

---

### 6. Catch-All: Unclear / Multi-Function / "Not Sure"

When the request does not fit cleanly into one function, or the member doesn't know what they need:

1. **Duty deacon takes the initial intake** — do NOT redirect the member to figure it out themselves.
2. Log the request in full as received.
3. Identify all tangible components → map to function owners.
4. Identify any spiritual/emotional components → flag for Elder referral.
5. Assign **one primary owner** responsible for following up with the member.
6. Notify secondary collaborators.
7. If genuinely ambiguous after 10 minutes of review, escalate to the deacon on duty or deacon coordinator — never leave a request unassigned.

> The member's experience must be seamless. They should hear from one person, not three.

## Part B — Taxonomy by Member Cohort

Organizing by cohort lets a duty deacon recognize the most common need patterns quickly. Each cohort section notes where self-help resources apply ([[self-help/index]]) and where spiritual needs split to Elders ([[escalation-to-elders]]).

---

### Cohort 1: Immigrants (Recent Arrivals & Established)

Immigrants often present with **clusters of interdependent needs** across multiple functions. Triage carefully — one presenting need often reveals several others.

#### Common Needs

| Need | Function | Notes |
|---|---|---|
| Translation / interpretation at appointments | Communication | Match language volunteer |
| Document translation (informal) | Communication | Legal documents → refer to nonprofit legal aid, NOT deacon-translated |
| DMV process navigation | Communication / Admin | Connect to resource; accompany if needed |
| Social Security Number (SSN) application navigation | Communication / Admin | Refer to SSA; deacons accompany, do NOT advise on eligibility |
| State ID / driver's license process | Communication / Admin | Connect to resource list; see [[self-help/index]] |
| Immigration paperwork navigation | Communication | **Referral ONLY to accredited rep or immigration attorney. Deacons do NOT advise on immigration law.** |
| Setting up a bank account | Communication / Admin | Connect to member or resource with experience; accompany if helpful |
| Setting up a phone plan | Operations / Communication | Basic assistance; see [[self-help/index]] for carrier list |
| Utilities setup (electric, gas, internet) | Operations / Communication | Assist with calls or online process |
| Lease / apartment application navigation | Communication / Admin | Explain process; do NOT cosign or advise on legal terms |
| Transportation (before license/car) | Operations | Recurring rides need regular driver volunteer assignment |
| Finding ethnic grocery stores or halal/kosher food | Communication | Maintain community resource list |
| Employment navigation | Communication | Connect to Helpers Directory; resume help → referral; credential recognition → refer to professional org |
| Credential / degree recognition process | Communication | Refer to state licensing board or accreditation body |
| Enrollment in benefits (SNAP, Medicaid, etc.) | Finance / Communication | Navigate process; do NOT determine eligibility |
| Financial hardship | Finance | Benevolence intake → [[benevolence/index]] |
| Isolation / loneliness (tangible community side) | Communication | Connect to small group, language-matched members |
| Spiritual distress, faith questions from displacement | → Elders | Retain tangible support in parallel |

> **Self-help:** Maintain a language-specific resource sheet in [[self-help/index]] for common agencies and processes. Update annually.

---

### Cohort 2: International Students

International students have predictable **semester-rhythm needs** — airport runs at start/end of semester, housing transitions, holiday isolation. Plan proactively.

#### Common Needs

| Need | Function | Notes |
|---|---|---|
| Airport pickup — arrival (semester start) | Operations / Drivers | Schedule in advance; confirm flight details |
| Airport drop-off — departure (semester end) | Operations / Drivers | Coordinate group runs when possible |
| Initial settling (grocery run, basics orientation) | Operations | Pair with local member "buddy" if possible |
| Furniture / household goods on move-in | Operations | Coordinate donation matching and delivery |
| Furniture pickup / disposal on move-out | Operations | Large-item logistics; coordinate early |
| Summer / holiday storage logistics | Operations | Connect to member with storage space or facility |
| Holiday host family | Communication | Thanksgiving, Christmas, Spring Festival, Eid, etc. — match proactively |
| Rides (ongoing — no car) | Operations / Drivers | Regular volunteer assignment preferred over one-off |
| ESL support or academic English help | Communication | Connect to ESL ministry or university resource |
| Academic support / study group | Communication | Connect to members in relevant field; NOT tutoring service |
| Health insurance navigation | Communication / Admin | Refer to university student health or navigator |
| Isolation / homesickness (tangible/community side) | Communication | Small group, buddy system, social events |
| Spiritual distress, faith questions | → Elders | Retain community connection support in parallel |
| Financial hardship (unexpected) | Finance | International students often ineligible for public benefits — benevolence may be primary option; see [[benevolence/index]] |
| Immigration status questions (OPT, CPT, visa) | Communication | **Referral ONLY — international student office or immigration attorney. Deacons do NOT advise.** |

> **Self-help:** Semester calendar triggers (Aug/Jan arrivals; May/Dec departures; Nov/Dec holidays) should prompt proactive outreach. See [[self-help/index]].

### Cohort 3: College Students (Domestic)

College students have lower-intensity but predictable cyclical needs. Many are semi-independent but resource-constrained.

#### Common Needs

| Need | Function | Notes |
|---|---|---|
| Rides (campus, church, errands — no car) | Operations / Drivers | Regular volunteer preferred |
| Move-in help (dorm or apartment) | Operations | Typically Aug and Jan |
| Move-out help | Operations | Typically May; often under time pressure |
| Furniture / household items (move-in) | Operations | Donation matching |
| Furniture disposal (move-out) | Operations | Coordinate early |
| Exam-season care packages / encouragement | Operations / Communication | Midterms and finals; coordinate with women's or youth ministry |
| Meals during illness or high-stress period | Operations | Short-term meal delivery or gift cards |
| Job / internship networking | Communication | Connect to Helpers Directory; member referrals |
| Budgeting / financial literacy | Finance | Refer to resource; deacons do NOT counsel finances |
| Unexpected financial hardship | Finance | Benevolence intake → [[benevolence/index]] |
| Connection to campus ministry or small group | Communication | Coordinate with campus ministry if church has one |
| Isolation (tangible/community side) | Communication | Social integration; spiritual side → Elders |

> **Self-help:** [[self-help/index]] should include a college student resource section (food pantry, campus counseling, financial aid office contact).

### Cohort 4: Families (Couples, Parents with Children, Single Parents)

Families present the broadest spread of needs across all four functions. Single-parent families often carry higher urgency.

#### Common Needs

| Need | Function | Notes |
|---|---|---|
| Meal train — new baby | Operations / Kitchen | Coordinate sign-up via Communication |
| Meal train — surgery or illness | Operations / Kitchen | Duration and dietary needs matter |
| Meal train — bereavement | Operations / Kitchen | Begin within 24–48 hrs of notification |
| Short-term childcare logistics (crisis) | Operations | Connecting to a trusted member for childcare; deacons do NOT provide childcare themselves |
| Kids' transportation (school, activities, appointments) | Operations / Drivers | Requires cleared driver; parental consent |
| Home repairs — minor to moderate | Operations | Safety-critical first |
| Moving help | Operations | Full crew coordination |
| Yard work / heavy labor | Operations | One-time or seasonal |
| Snow removal | Operations | Urgent in storm season |
| Financial hardship (bills, rent, groceries, medical) | Finance | Benevolence intake → [[benevolence/index]] |
| Benefits navigation (SNAP, WIC, CHIP, Medicaid) | Finance / Communication | Navigate enrollment; refer as needed |
| Employment transition support | Communication / Finance | Helpers Directory for networking; benevolence for bridge gap |
| Marriage difficulties (practical side: finances, childcare) | Finance / Operations | Spiritual/relational side → Elders |
| Parenting support (practical side: resources, logistics) | Communication / Operations | Spiritual/guidance side → Elders |
| Family conflict (tangible side: housing, finances) | Finance / Operations | Reconciliation/mediation side → Elders |
| Domestic safety concern | **Immediate: refer to 911 / DV resources first** | Notify Elders; secure safety logistics if needed |

> **Self-help:** Refer families to community resource lists in [[self-help/index]] for childcare, food pantry, and family services.

> **Elder split:** Marriage and parenting guidance (spiritual, counseling) → [[escalation-to-elders]]. Deacons retain the practical/tangible dimensions.

### Cohort 5: Elderly Members

Transportation is the single highest-volume need for elderly members. Proactive relationship-building prevents needs from going unreported.

#### Common Needs

| Need | Function | Notes |
|---|---|---|
| **Transportation to church service** | Operations / Drivers | Often recurring — assign a consistent driver | 
| **Transportation to medical appointments** | Operations / Drivers | Doctor, specialist, dialysis, therapy — recurring scheduling preferred | 
| Transportation for pharmacy / errands | Operations / Drivers | Can batch with other runs |
| Transportation to hospital visits (visiting family) | Operations / Drivers | Coordinate timing |
| Grocery shopping — in-person assistance | Operations | Some members want company, not just delivery |
| Grocery delivery / pharmacy delivery | Operations | For fully homebound members |
| Home maintenance — minor repairs | Operations | Plumbing, electrical (low-risk), fixtures |
| Home maintenance — accessibility (ramp, grab bar, handrail) | Operations | May require skilled volunteer; track contractor referrals |
| Yard work — ongoing or seasonal | Operations | Assign consistent volunteer where possible |
| Snow / ice removal | Operations | Priority Urgent in winter — fall risk |
| Technology help (phone, tablet, computer, TV) | Communication / Operations | Patience and follow-up matter; IT sub-lane for complex issues |
| Video call setup (family connection) | Communication | One-time setup + periodic check-in |
| Meals (illness, post-hospitalization, ongoing isolation) | Operations / Kitchen | Distinguish short-term from ongoing |
| Medicare / insurance paperwork navigation | Admin / Communication | Navigate and explain; refer to SHIP counselor for complex questions |
| Medical appointment paperwork (forms, records requests) | Admin | Assist with completion; do NOT advise on medical decisions |
| Benefits navigation (Medicare Part D, Medicaid, SSI) | Finance / Communication | Refer to benefits navigator for eligibility questions |
| Homebound visitation logistics (scheduling, coordination) | Admin | Pastoral/spiritual visitation → Elders; deacons coordinate the practical logistics |
| Isolation / loneliness (tangible/community side) | Communication | Regular structured contact; spiritual side → Elders |
| End-of-life logistics (practical: transport, documents, meals) | Operations / Admin | Spiritual preparation → Elders; legal/estate → refer to attorney |
| Financial exploitation concern | Finance / Admin | Notify Elders; refer to Adult Protective Services if warranted |
| Emergency or safety check | **Call 911 first if life-safety** | Notify Elders; assign a deacon point-of-contact |

> **Self-help:** [[self-help/index]] should include SHIP (State Health Insurance Assistance Program) contact, local senior services agency, and Meals on Wheels information.

> **Elder split:** Pastoral visitation, spiritual care, grief, end-of-life spiritual preparation → [[escalation-to-elders]]. Deacons retain all logistics and practical support.

## Multi-Function Request Handling Summary

| Pattern | Primary Owner | Collaborators |
|---|---|---|
| Meal + transportation needed | Operations | Drivers sub-lane |
| Financial hardship + paperwork | Finance | Administration (intake) |
| New arrival with multiple needs | Communication | Operations, Finance, Admin as needed |
| Bereavement with meals + pastoral | Operations (meals/logistics) | → Elders (pastoral); Communication (announcement) |
| Home repair + financial need | Operations (repair) | Finance (benevolence if cost involved) |
| Elderly with transport + tech help | Operations (transport) | Communication / IT (tech) |
| Unclear / multi / "not sure" | **Duty deacon holds** until assigned | Coordinate within 24 hrs |
